# Data

This folder contains the processed summary datasets used in the final analysis and presentation.

## Included

- `sales_by_segment.csv` — total sales by customer segment.
- `segment_summary.csv` — customer count, average spend, units and price metrics by segment.
- `monthly_store_metrics.csv` — monthly store-level metrics used for trial/control analysis.

## Source datasets

The original Quantium simulation source files (`QVI_transaction_data.xlsx`, `QVI_purchase_behaviour.csv`, and `QVI_data.csv`) are not included in this public repository. The repository therefore focuses on the analysis code, processed outputs, visualizations, and final presentation rather than redistributing the original simulation data.

The Python scripts document the preparation and analysis workflow used to produce the included outputs.
