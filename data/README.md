# Data

This folder contains the processed summary datasets used in the final analysis and presentation.

## Included

- `sales_by_segment.csv` — total sales by customer segment.
- `segment_summary.csv` — customer count, average spend, units and price metrics by segment.
- `monthly_store_metrics.csv` — monthly store-level metrics used for trial/control analysis.

## Source datasets

The original Quantium simulation source files are intentionally not included in this public repository:

- `QVI_transaction_data.xlsx`
- `QVI_purchase_behaviour.csv`
- `QVI_data.csv`

The repository therefore focuses on the analysis code, processed outputs, visualizations, and final presentation rather than redistributing the original simulation data.

If you have the original simulation files locally, place them in this `data/` folder before running the raw-data workflows in `scripts/`.
