# Quantium Data Analytics Virtual Experience — Chips Category Review

Completed as part of the [Quantium Data Analytics Job Simulation](https://www.theforage.com/) on Forage.

## Project overview
Analysis of a retail chips category for a fictional client, covering:
1. **Data preparation & customer analytics** — cleaned and merged transaction/customer
   data, segmented customers by life stage and spending tier, and identified the
   highest-value growth segment.
2. **Experimentation & uplift testing** — selected statistically matched control
   stores and evaluated whether a store layout trial drove a significant sales uplift.
3. **Commercial presentation** — translated both analyses into a client-ready deck
   using the Pyramid Principle (conclusion first, evidence after).

## Repo structure
- `scripts/` — Python analysis code (pandas, matplotlib, scipy)
- `data/` — summary output tables (segment- and store-level metrics)
- `charts/` — visualizations generated from the analysis
- `presentation/` — final client-facing deck (PDF and editable PPTX)

## Key findings
- Mainstream Young & Midage Singles/Couples are the standout growth segment:
  a large customer base that over-indexes on premium brands and larger pack sizes.
- 2 of 3 trial stores showed a statistically significant sales uplift during the
  trial period, driven by increased customer counts rather than higher spend per visit.

## Tools
Python (pandas, numpy, matplotlib, scipy), python-pptx
